# 项目说明
### 为何会有这样该项目
购买了一把前行者键盘，但发现键盘提供网页驱动，但没有提供mac端的声光律动插件
切windows端仅提供有线律动效果故借助官方驱动编写该项目

本项目仅用于学习使用，请勿用于非法商业用途，项目用于提供键盘的声光律动效果，由于本人仅有x87键盘，仅在x87键盘验证验证环境为macos27.2bata，由于内嵌官方网页驱动，故功能和网页驱动保持一致，如有不妥之处请联系作者，如果好用的话还请点个star

# 常见问题

| 现象 | 处理 |
|---|---|
| 找不到键盘 | 确认 2.4G 接收器/有线连接；蓝牙形态没有厂商通道；关闭其它占用 HID 的软件。 |
| 网页驱动空白 | 确认打开的是 `eweadn-macfix` 而不是鼠标版；查看 `~/Library/Logs/PeripheralHub/hidweb.log`；端口被占用会自动回退。 |
| 律动没有权限 | 系统设置 → 隐私与安全性 → 屏幕与系统音频录制，勾选 `eweadn-macfix`，⌘Q 后重开；必要时 `tccutil reset ScreenCapture local.eweadn.macfix`。 |
| 律动有画面但键盘不亮 | 确认键盘处于有线/2.4G 厂商通道；蓝牙不可用；确认亮度不是 0。 |
| “无法验证开发者” | 右键「打开」；或移除隔离属性 `xattr -dr com.apple.quarantine /Applications/eweadn-macfix.app`。 |
| 想彻底卸载 | 删除 App；按需清理 `defaults delete local.eweadn.macfix`、`~/Library/WebKit/local.eweadn.macfix`，并 `tccutil reset ScreenCapture local.eweadn.macfix`。 |
